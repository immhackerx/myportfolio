PERSONAL PORTFOLIO - CS101 (HTML and CSS only)

HOW TO OPEN
Unzip the folder, then double-click index.html. No installs needed.
Keep the folder structure (index.html, css/, images/) unchanged.
Google Fonts and the map iframe need an internet connection.

HOW TO EDIT
1. Open index.html in any text editor (e.g. VS Code, Notepad).
2. Search for the word REPLACE and for [square brackets]. Each one marks text to change.
3. Your photos: put them in images/ and change the src="..." of the <img> tags.
   (The current .svg files are placeholder artwork. Delete or keep them.)
4. Contact links: change the href values in the Contact section.
5. Map: openstreetmap.org > Share > HTML, then copy the src URL into the <iframe>.
6. Colours: edit the variables at the top of css/style.css (:root).
